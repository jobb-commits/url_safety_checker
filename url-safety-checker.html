URL safety checker

Paste a link before you click it. The checker looks at how the address is built, whether it imitates a well known site and if the domain actually exists. Everything runs in your browser.

Self Test

Runs the address checks against a labelled set of phishing style and legitimate URLs then reports how often the verdict is right. The test URLs are synthetic patterns, not live malicious sites.

Limitations. Browsers block SSL certificate and redirect lookups, so those are not checked. Domain age comes from RDAP, which only some registries allow from a browser. Heuristics cannot detect a legitimate site that has been hacked, and attackers can adapt to known rules. A clean result means no red flags were found, not that a site is safe.
